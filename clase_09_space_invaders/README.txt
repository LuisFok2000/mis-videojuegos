SPACE INVADERS - Actividad 9

Colocar la carpeta space_invaders al lado de engine (sin modificar engine).

Desde la carpeta que contiene engine y space_invaders ejecutar:
    python -m space_invaders.main

Requiere pygame: pip install pygame

Controles: flechas izquierda/derecha para moverse; espacio para disparar; ESC para salir.
